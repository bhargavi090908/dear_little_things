# Dear Little Things — multi-step prototype

This version follows the customer journey:
1. Pick an occasion.
2. Browse three templates with example prices shown before choosing.
3. Enter gift details and see the selected price again.
4. Generate a preview and edit details if needed.

## Files
- index.html — page structure, occasion cards, template and form sections
- style.css — responsive pastel style
- script.js — navigation, sample templates/prices, bilingual UI, preview generation

## Test locally
1. Extract the ZIP.
2. Keep all three files together in one folder.
3. Open index.html in a modern browser.
4. Click Birthday (or another occasion), compare template cards and example prices.
5. Choose a template, fill in a name and message, and click Create my preview.
6. Try editing details, selecting a photo, changing colours, and switching English/Telugu.

## Important
The prices (₹99/₹199/₹299) are illustrative placeholders, not live offers or validated market prices. This demo does not accept payments, save orders, publish a gift URL, or upload form content. The optional photo is previewed locally. Interface language changes, but user-written messages are not automatically translated.

Before taking real orders, ask a parent/guardian to help check age-appropriate accounts, hosting, payments, privacy, and terms. Test with fictional information first and get permission before using other people's photos. For saved public gift links, build access controls and a deletion process before collecting customer content.
